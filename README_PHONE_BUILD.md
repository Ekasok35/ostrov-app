# Собрать APK OSTROV только с Android-телефона

Для сборки не нужен Google Play и не нужен собственный компьютер. Нужен аккаунт GitHub и браузер телефона. Сборка выполняется на GitHub Actions в облаке.

## Шаги

1. Скачайте ZIP проекта OSTROV на телефон.
2. В браузере откройте https://github.com/new и создайте приватный репозиторий, например `ostrov-app`. Не добавляйте README, license или gitignore при создании.
3. На странице пустого репозитория нажмите **Add file → Upload files** и загрузите скачанный ZIP-файл как один файл. Нажмите **Commit changes**.
4. Откройте **Code → Codespaces → Create codespace on main**. Если Codespaces недоступен или требует включить оплату, не подтверждайте платёж; потребуется другой способ сборки.
5. В терминале Codespaces выполните команды:

```bash
unzip ostrov_app_source.zip
cp -a ostrov_app/. .
rm -rf ostrov_app ostrov_app_source.zip
git add .
git commit -m "Add OSTROV Flutter source and Android build workflow"
git push
```

Если ZIP назван иначе, замените `ostrov_app_source.zip` в команде на точное имя файла.

6. Откройте вкладку **Actions** репозитория. Запустится **Build OSTROV Android APK**. Дождитесь зелёной галочки. Если сборка упала, откройте её и сохраните текст ошибки — он нужен для исправления.
7. Откройте успешный запуск workflow, внизу найдите **Artifacts** и скачайте `ostrov-android-apk`.
8. Распакуйте скачанный архив на телефоне. Внутри будет `app-release.apk`. Откройте APK и разрешите установку из этого источника, если Android спросит.

## Важно

- GitHub Actions собирает APK в облаке; GitHub-аккаунт и доступность Actions/Codespaces зависят от условий GitHub.
- APK из этого workflow — тестовая сборка, подписанная ключом debug автоматически созданного проекта. Для публикации в Google Play понадобится отдельный защищённый release keystore и сборка AAB.
- Сейчас это клиентский прототип. Реальные заказы, водительское приложение, сервер, SMS и платежи ещё не реализованы.
- Не вводите реальные платёжные или паспортные данные в прототип.
- Если GitHub показывает ошибку, не пытайтесь публиковать APK; передайте лог сборки для диагностики.
